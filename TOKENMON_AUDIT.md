- **Date:** 2026-09-16

## Summary

Sweep of TokenMon’s live SwiftUI/AppKit menu-bar agent (LSUIElement + MenuBarExtra `.window`): cookie/file auth, pollers, Daily Budget math, cookie capture, CI gates, and TokenMonTests. Auth is still 0600 Application Support files (not Keychain), Grokbot still borrows `CursorAuthSession`, and CI already runs both `make test-core` and `make test`. Highest risk is expired Cursor/Claude sessions that land on 200 HTML, cookie-jar blast radius on Grok/ChatGPT capture, in-flight poller races (especially ChatGPT), and Daily Budget bars that treat any downward pool-% tick as a full window reset. No Critical ship-blockers (numbers are last-good or bar-inflated, not recomputed against the wrong billing cycle; stolen session files remain local 0600).

## Checklist (passed)

- 401/403 map to unauthorized in `AuthenticatedRequest`; Grok REST/gRPC rethrow unauthorized and do not swallow probes.
- Grok JSON/gRPC decode failure degrades (next candidate / empty products) instead of crashing; `WeeklyUsageSnapshot` clamps used%.
- `PollingLoop` honors `Task.isCancelled` and shrinking intervals; Grok `UsagePoller` pauses on sleep and refreshes on wake with backoff.
- `DailyBudget` / Grokbot / Claude / Cursor refuse calendar-month/week guesses; weekly vs subscription-month builders stay distinct (OpenCode weekly Daily Budget is the exception, reported above).
- Grokbot borrows `CursorAuthSession` (`cursor_auth_` prefix; no second cookie store); Cursor sign-in also `refreshNow()`s `grokbotPoller`.
- `AppModel.forwardChanges` relays settings, history, hourly/daily stores, every registry poller, all auths, and `UpdateChecker` so MenuBarExtra observes `AppModel` only.
- Menu bar label is AppKit `NSImage` (`MenuBarLabelView` → `MenuBarStatusRenderer`); cache key includes live `menuBarAppearanceName`; `AppleInterfaceThemeChangedNotification` clears `NSCache`. `GeometryReader`/`Circle` stay in-panel.
- Credentials are mode-0600 Application Support files via `FileBackedStringStore` / `FileBackedCredentialStore`, not Keychain. `AppSupport` directory is created 0700. `CredentialStoreTests.testFilePermissionsAreUserOnly` locks mode 0600.
- ChatGPT session missing `accessToken` → unauthorized; Grokbot non-JSON body → unauthorized (WorkOS HTML); Grokbot missing `usagePercent` with allowance fields parses as 0%.
- Cursor `totalPercentUsed` preferred over auto/api; plan cents÷100.
- No live secrets, cookies, signing certs, or telemetry SDKs in `TokenMon/` or `TokenMonTests/` (OpenRouter/Claude strings are fake fixtures). PrivacyInfo: `NSPrivacyTracking` false, UserDefaults CA92.1 only, empty collected types.
- `project.yml` and pbxproj agree: bundle `com.modelmonitor.app`; `ENABLE_HARDENED_RUNTIME YES`; entitlements + PrivacyInfo paths. Info.plist: `LSUIElement` true, no ATS exceptions.
- Empty `TokenMon.entitlements` is documented in `Docs/NOTARIZATION.md` (unsandboxed OpenCode local DB).
- Grok REST/gRPC/CLI URLs in `UsageClient.swift` match `Docs/AUTH_AND_ENDPOINTS.md`.
- CI runs `make lint`/`format`, gitleaks dir+detect on fetch-depth 0, xcodegen-drift, `make test-core`, and `make test`. Makefile secrets/lint fail closed if tools are missing. `TokenMon.xcscheme` does not skip TokenMonTests. Toolchain pins: SwiftLint 0.59.1, SwiftFormat 0.62.1, XcodeGen 2.46.0, gitleaks 8.30.1.
- Cookie providers subclass `ProviderAuthSession` except OpenRouter (bearer key, reported). Isolated `WKWebsiteDataStore.nonPersistent()` per provider; capture logs cookie counts not values.
- Cursor/Claude/OpenCode capture policies set `essentialCookieNames`; allowlist tests drop `_ga` and foreign domains.
- `AuthenticatedRequest.mapError` never includes response bodies (tested).
- UpdateChecker is notify-only GitHub latest (no download/install). OpenRouter UI uses `SecureField` placeholders only.
- OpenRouter `markSessionInvalid` keeping the key on disk is explicit and tested (re-probe behavior reported).
- Each provider has its own `isRefreshing` flag; URLSession work is awaited on the main actor so two `refreshNow`s on the same poller cannot interleave writes.
- Cookie pollers except ChatGPT re-check `auth.isSignedIn && !needsSignIn` after await before publishing a snapshot.
- `HistoryStore` coalesces same-calendar-day SwiftData rows, skip-window for <0.05% noise, 200-cap recent, and `NSApplication.willTerminate` flush.
- `DailyQuotaDeltaStore` and `HourlyDeltaActivityStore` mutate and persist only on MainActor; AppSettings UserDefaults writes stay on MainActor.
- All cookie sign-in windows wrap `ProviderSignInSheet` (ChatGPT, Claude, Cursor, Grok `SignInView`, OpenCode); no parallel custom WebView sheets.
- `WeeklyDailyBudgetBarsView` vs `MonthlyDailyBudgetBarsView` stay distinct; `DailyBudget.subscriptionMonth` / `buildWeeklyWindowDays` refuse calendar-month/week guesses.
- OpenCode `monthDailyBudgetDays` routes through `DailyBudget.buildSubscriptionMonthLast7Days` (console `resetsAt` or Go anniversary), not calendar month of now.
- No commented-out function/struct blocks or unreachable-after-return production paths found under `TokenMon/`.
- Provider panels use `ProviderSignOutButton` two-step confirm; signed-out / Refreshing… / lastError / snapshot branches exist on Grok, Cursor, Claude, ChatGPT, OpenCode, OpenRouter, Grokbot.
- Overview hourly chart has an explicit empty caption when no activity.

- `AuthenticatedRequestTests` map HTTP 401/403 to `UsageError.unauthorized` without leaking bodies.
